# 01. プロダクト仕様（Product Spec）

## 1. ビジョン

**「一人ひとりに、自分だけの Digital Twin と、その上で伴走する AI コーチを。」**

人は「なりたい自分（ToBe）」を漠然と持っていても、
- 今の自分（AsIs）を客観的に把握できていない
- 何をすれば近づくのか、日々の行動に落とせない
- 続かない／振り返れない／孤独

という壁にぶつかる。

本プロダクトは、ユーザーの分散したデータと対話から **Personal Ontology（自己の運用オントロジー＝デジタルツイン）** を構築し、
その上で動く AI エージェントが、**AsIs を可視化し、ToBe との Gap を埋める行動に日々伴走する** ことで、
「自己理解 → 目標 → 行動 → 学習」の閉ループを一人ひとりに提供する。

### 既存プロダクトとの違い（ポジショニング）

| カテゴリ | 例 | 本プロダクトとの違い |
| --- | --- | --- |
| ライフログ / 想起 | Rewind, Limitless, Mem | 「記録・想起」止まり。**構造化された自己モデルと目標志向の行動**がない |
| メモ / セカンドブレイン | Notion AI, Obsidian, Reflect | 情報の器。**自己の状態モデル・介入エンジン**がない |
| 習慣 / コーチング | Fabulous, Rocky.ai, BetterUp | 汎用テンプレ。**個人のオントロジーに根ざした文脈理解**が浅い |
| パーソナルAI | Personal.ai, Pi | 会話相手。**行動に接続された Operational な層（予定化・推薦・接続）**が弱い |

**差別化の核心 = Operational Ontology（行動に接続された自己モデル）× AsIs→ToBe の閉ループ。**
単なる賢いチャットボットではなく、「自分のことを構造的に理解し、行動を起こし、その結果から学ぶ運用基盤」であること。

## 2. ターゲット & ペルソナ

### 【確定】ローンチ・ウェッジ: ソロ起業家 / インディーハッカー
「成長したい全員」は捨て、最初の1セグメントに殺し込む。選定理由:

- **ToBe が具体・測定可能**: 「v1 ローンチ」「初収益」「MRR $1k」など、前進が数字で見える。
- **痛みが切実で伴走価値が高い**: 一人で作る孤独、地味な作業の連続、外部アカウンタビリティの不在。
- **データがデジタルに揃う**: GitHub / カレンダー / Notion / X など、AsIs を作る材料が手元にある。
- **Founder-Market Fit**: オーナー自身がこのセグメントに近く、secret を持てる。
- **獲得ループと相性が良い**: build-in-public 文化があり、産出物のシェアがそのまま流入になる。

JTBD:「一人で作る孤独の中で、なりたい姿（出荷/収益）に向かって**前進し続けている実感**を保ちながら、今日出荷する"たった1つ"に集中させてほしい」

> 拡張候補（ウェッジ検証後）: キャリアピボット/スキル獲得層、難関試験の学習者。いずれも「ToBe が測定可能・締切あり」が共通条件。

### Jobs To Be Done（機能的・情緒的・社会的）
- 機能的:「バラバラなデータから今の自分を可視化し、目標に紐づく次の一手を出してほしい」
- 情緒的:「一人で頑張らず、自分を深く理解した存在に伴走してほしい（安心・自己効力感）」
- 社会的:「変わろうとしている自分を肯定的に見て、適切な人・本・機会につないでほしい」

## 3. 中核となる 4 つのプロダクト柱

### 柱① Import — 自分のデータを取り込む
Slack / Notion / Google カレンダー / Deep Research の成果 / SNS / ブログ / プロフィールサイト などを接続。
生データを正規化し、後述のオントロジーに写像していく。**すべての事実は出典（lineage）を持つ**。

### 柱② Interview — 対話で自分を教えていく
AI からの「問いかけ」に答えることで、データだけでは分からない **価値観・原体験・こだわり・関係性** をオントロジーに埋めていく。
- 能動学習（Active Learning）:「今、埋めると最も価値が高い空白」を優先して質問。
- 質問はしつこくない。1 日 1〜3 問、あるいは Weekly Review の中で自然に。

### 柱③ Model — Personal Brain / Ontology を構築・継続更新
取り込みデータ＋対話から、ユーザーの **自己モデル（デジタルツイン）** を構築。
- 各事実に **確信度（confidence）** と **出典** を保持し、時間とともに更新・強化・忘却。
- 「AsIs（今の状態）」を常に算出可能な状態に保つ。

### 柱④ Coach — Digital Twin が伴走する
ユーザーがアプリ上で **目標・達成したいこと・なりたい理想像・テーマ・行動指針** を設定すると、
Digital Twin AI が ToBe との Gap を分析し、伴走する。
- 学習計画の設計と更新
- コーチング対話（GROW モデル等）
- 習慣化支援（Tiny Habits / cue-routine-reward、Weekly Review）
- 本・人・機会などのリソース提案と「つなぎ」

## 4. 主要ユーザー体験（Key Flows）

### 4.1 オンボーディング（初回 30 分で「見られている感」を作る）
1. サインアップ → **プライバシーの約束**を提示（データ主権・学習に使わない・削除可）。
2. コネクタを 1〜3 個接続（まず Google カレンダー + Notion or Slack を推奨）。
3. 取り込み中に **「あなたについての最初の 5 問」** に回答（価値観・今のテーマ・理想像の断片）。
4. 数分で **「あなたの現在地マップ（AsIs スナップショット）」** を提示 →「もっと知りたい」動機づけ。
5. 最初の **ToBe（3 ヶ月テーマ or 1 つのゴール）** を一緒に設定。

### 4.2 デイリー体験 — Morning Brief / ナッジ
- 朝:「今日のブリーフ」= 今日の予定 × ゴール × 体調/エネルギー × 今日の 1 つの重要行動。
- 日中: 文脈に応じたナッジ（例:「14 時に空きあり。学習ブロック入れる?」）。
- 夜: 30 秒の振り返り（今日の一言ジャーナル／気分ログ）。

### 4.3 ウィークリー体験 — Weekly Review（自己 OS の定例儀式）
- 今週の AsIs 変化（momentum / streak / 各ゴールの Gap 推移）を可視化。
- うまくいったこと・ドリフト（逸れ）の検知と原因の対話。
- 来週の計画を Twin と共同編集。ここで Interview の問いも自然に混ぜる。

### 4.4 対話（いつでも相談できるバディ）
- チャット / 音声で相談。Twin は**自分の全文脈（オントロジー＋メモリ）を踏まえて**応答。
- 例:「最近やる気が出ない」→ 価値観・最近のログ・睡眠/予定過密を踏まえ、原因仮説と小さな一手を提示。

### 4.5 リソース接続（本・人・機会へのブリッジ）
- スキル Gap に対し、**具体的な本・記事・講座・人**を推薦し、カレンダー/リーディングキューに投入。
- 関係性グラフから「この人に相談すると良さそう」を提案（承諾を得てから）。

## 5. 機能一覧（レイヤ別）

### Personal OS（基盤）
- コネクタ接続 / OAuth 管理 / 同期状況の可視化
- Personal Data Vault（暗号化・エクスポート・削除・データ系譜の閲覧）
- 権限・同意管理（コネクタ単位・データ種別単位の consent）

### Ontology / Brain（自己モデル）
- 自己モデルの閲覧・編集（「AI が私についてこう理解している」を可視化・修正可能）
- 確信度・出典の表示、忘却/更新
- AsIs ダッシュボード（価値観・スキル・関係性・テーマ・習慣・状態）

### Agent / Coach（伴走）
- ゴール / テーマ / 行動指針 / 理想像の設定と管理（OKR ライク）
- Gap 分析・介入提案（学習計画・習慣・リソース・接続）
- Morning Brief / Weekly Review / コーチング対話
- ナッジ・リマインド・再計画（ドリフト検知時）

### 信頼・安全
- 透明性:「なぜこの提案をしたか」を出典付きで説明可能（説明可能性）。
- ユーザーコントロール: いつでもオフ・修正・削除できる。

## 6. 成功指標（North Star & KPI 案）

- **North Star**:「ユーザーが自認する ToBe への接近（週次で計測する自己評価 × 行動実績）」。
- 先行指標:
  - Weekly Active + Weekly Review 実施率（習慣として定着しているか）
  - オントロジーの充足度 / 確信度の上昇（自己モデルの成熟）
  - 提案の受容率（Twin の提案 → 実行に移った割合）
  - ゴール別 Gap の縮小トレンド、習慣の streak
- 遅行指標: 目標達成率、継続率（リテンション）、NPS / 情緒的アタッチメント。

## 7. リスクと論点（要議論）

- **プライバシー / 信頼**: 最もセンシティブな個人データを扱う。データ主権・非学習・E2E をどこまでやるか（→ アーキテクチャ参照）。
- **精度と過信**: 誤った自己モデルで誤った助言をするリスク。確信度・出典・ユーザー修正で緩和。
- **依存 vs 自律**: コーチとしては「自律を育てる（自己決定理論）」設計にする。依存させない。
- **コールドスタート**: データが少ない初期に価値を出せるか（Interview 主導で補完）。
- **Time-to-value**: 30 分以内に「見られている・理解されている」体験を作れるか。
- **収益モデル**: 個人向けサブスク（月額）＋高付加価値コーチング枠、B2B2C（企業の人材開発・福利厚生）などは別途検討。
