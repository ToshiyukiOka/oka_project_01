# PoC 結果: 語り継ぐべき名曲 Top 50（全 223 曲で算出）

> `npm run report` の出力（[`out/RANKING.md`](../out/RANKING.md)）を読み解くための分析メモ。
> 各曲の「なぜ語り継ぐべきか」（データの証言と文脈の解説）は `out/RANKING.md` にある。

## 前提（この結果が何であり、何でないか）

- **何であるか**: 1927〜2023 年に発表された邦楽 223 曲について、Web 検索で証拠付きのカバーを集め（約 1,100 件。出典 URL のある 1,077 件をグラフに使用）、CoverRank と語り継ぎ補正で並べた結果。すべての曲を同じ収集手順でそろえて調べている。
- **何でないか**: 網羅的な調査ではない。証拠が 3 件未満の曲が **65 曲（29%）** あり、その多くは見つからなかっただけと考えられる（「世界に一つだけの花」「北酒場」0 件、「負けないで」1 件、「少年時代」「津軽海峡・冬景色」2 件、「涙そうそう」3 件など）。したがって Top 50 は、実質的に**証拠が十分集まった約 160 曲の中での順位**であり、レポートではそれ以外の曲を「評価保留」として明示している。
- 候補 223 曲は人が選んだもので、ここに無い曲はそもそも評価していない。本番では、候補の生成もカタログ（JASRAC J-WID、MusicBrainz）から機械的に行う。

## 読み取れること

### 1. 頑健なのは最上位だけ
- **1 位の「上を向いて歩こう」だけが、どう揺らしても 1〜2 位**に収まる。海外の歌い手を含む 17 組、5 世代に歌い継がれ、実効ジャンル数は 5.9 で全曲中最大。数・質・世代・越境のどの軸でも突出している。
- 2〜12 位は、証拠の欠損に対して 1 桁台から 20 位台まで動く。13 位以下は区間が広く、**順位の細かい差には意味がない**。PoC として正しく言えるのは「この 50 曲は、伝承の証拠が厚い曲群である」ところまでである。

### 2. PageRank 化で何が変わったか（素朴なカバー数順位との Kendall τ = 0.83）
- **上がった曲 = 「歌い手の歌い手」に選ばれた曲**
  - 「あの素晴しい愛をもう一度」は、カバー数順で 54 位相当から **7 位**に上がった。井上陽水（自作曲が多く歌い継がれている）の 1 票が 45% を占める。
  - 「港町ブルース」は 82 位相当から **18 位**。桑田佳祐・石川さゆり・ザ・ピーナッツ・藤圭子の票による。
  - 「ロビンソン」はカバー 5 件で **31 位**。桑田佳祐と絢香の票による。
- **下がった曲 = 短期集中のカバー**: 「香水」はカバー 9 件（カバー数順で 25 位相当）だが、すべて 2020 年に芸能人が相次いで投稿した「歌ってみた」で、権威の低い投票者による。持続補正 ×0.60 もかかって **106 位**。設計どおり、流行の熱量と「語り継ぎ」を分けられている。
- **多作なカバー歌手の 1 票は薄まる**: 中森明菜・徳永英明・May J. は、Top 50 のうち 7〜8 曲に票を入れているが、1 曲あたりの寄与は 1〜4% にとどまる。これは票を割る仕組みが意図どおり働いた結果である。

### 3. 偏りのリスク: 一つの重い投票者への集中
- サザンオールスターズ（桑田佳祐・原由子を同一主体として束ねた 1 つの投票者）は、自作曲が広く歌い継がれているため権威が高い。Top 50 のうち 5 曲で最大の票（「学生時代」「港町ブルース」「いい日旅立ち」「ロビンソン」「ブルー・ライト・ヨコハマ」）、1 曲で 2 番目の票（「あの素晴しい愛をもう一度」）を持つ。
- これは「歌い手の歌い手」効果としては正しい。ただし、そのカバーの多くはテレビ特番などの**企画での選曲**とみられる。設計書 §6 の「番組・企画盤を 1 ノードに束ねて票を分割する」対策を入れないと、一つの企画の選曲が複数曲の順位を押し上げうる。本番では必ず対策する。

### 4. 年代の分布
- Top 50 の年代別内訳は、1920 年代 1・1940 年代 4・1950 年代 1・1960 年代 8・**1970 年代 18**・1980 年代 9・1990 年代 6・2000 年代 2・2010 年代 1。
- 1970 年代が厚いのは、2000〜2010 年代のカバー・アルバム文化（女性歌手による昭和歌謡カバー、「VOCALIST」シリーズなど）がこの時代の曲を多く掘り起こしたことと、半世紀を生き延びた曲が既に選別されていることの両方による。
- 新しい曲は構造的に不利なので、同時代の曲どうしで比べる「**未来の名曲候補**」枠を別に出している。上位は 雪の華・紅蓮華・secret base・ひまわりの約束・千の風になって・千本桜。

### 5. 証拠の種類への依存
- 検索結果のタイトルで直接裏付けられた証拠（491 件）だけで再計算すると、Top 50 のうち残るのは **27 曲**（Kendall τ = 0.44）。順位は、検索要約を根拠にした証拠に大きく依存している。
- これは PoC の最大の弱点であり、YouTube の Art Track（作家クレジット付きの商業音源）とカタログ API による網羅的なプロ層の証拠で置き換えるのが次の一手になる。

## 次の一手（優先順）

1. **網羅的な証拠に置き換える**: YouTube Data API（`npm run youtube`、要 API キー）で Art Track 層を作る。あわせて、MusicBrainz / J-WID など、ネットワーク許可が必要なカタログで補完する。評価保留の 65 曲を最優先にする。
2. **企画・番組の束ね**: 同じアルバム、同じ番組から出たカバーを 1 票に束ねる（§6）。
3. **時間分割バックテスト**: カバーの公開年が取れたら、2015 年までのグラフで 2016〜2025 年に新しい世代が歌い直す曲を予測できるかを、素朴なカバー数・再生数と比べる（§7）。これが「本質ランキング」の妥当性を示す主指標になる。
4. **候補の機械生成**: 人が選んだ 223 曲から、カタログ全体へ広げる。
